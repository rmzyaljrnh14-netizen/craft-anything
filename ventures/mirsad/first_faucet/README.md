# مِرصد الصنبور · Mirsad Faucet Desk

مشروع مستقل لتجربة **Final Autoclaim**. افتح `/trial/` لحساب نافذتك وتدوين وارد مؤكد منك، أو `/trial/offline.html` لتنزيل الدفتر نفسه. يظل السجل في تبويبك؛ ملف الاستئناف الذي تنزّله ليس مشفّرًا. لا تسجّل الأداة في الصنبور، ولا تنفّذ إعلانات أو مطالبات أو تحويلات. نطاق النشر هو هذا المجلد فقط، وليس بقية مستودع Craft Anything أو مشاريع مِرصد الأخرى.

## التشغيل والتطوير

من `ventures/mirsad/first_faucet`، بمكتبتَي Python وNode القياسيتين دون تثبيت تبعيات أو إعداد مفاتيح:

```sh
node --test trial/model.test.cjs
python3 -m unittest discover -s tests
python3 build_site.py
python3 watch.py --port 8080
```

- `trial/`: نموذج الحساب والحالات، الواجهة العربية والاختبارات. `trial_bundle.build()` ينتج ملف HTML مكتفيًا بذاته، ببصمات CSP وممنوع عليه الاتصال بالشبكة. النسخة المستضافة ونسخة التنزيل من نفس المصدر.
- `hosted/`: الصفحة الرئيسية لنسخة Vercel. `api/status.py`: دالة WSGI للرصد العام، تستعمل المحلل نفسه في `watch.py` **عند الطلب**، مع تخزين مؤقت حتى ساعة، وتراجع عند فشل المصدر. لا Cron ولا خيط دائم أو قاعدة بيانات أو صلاحيات لصنبور على Vercel. اخترنا هذا عمداً بدل نقل حلقة `watch` إلى دالة قصيرة العمر. `watch.py` المحلي وحده يشغّل عاملًا مستمرًا ما دام الأمر يعمل.
- `facts.json`: لقطة يدوية من [الدليل](https://faucetpay.io/faucet/profile/105011) و[الحدود](https://autofaucet.dutchycorp.space/FAQ.php) و[الرسوم](https://faucetpay.io/fees). عند مراجعتها حدّث تاريخها بعد التحقق فقط. حدّ الصلاحية سبعة أيام للحدود ويومان للأسعار. لا يُعرض تقدير عند غياب الأدلة. لا تعني مقارنة العملات أن دفعة قد وصلت.
- `build_site.py` يُعد فقط خمس ملفات عامة في `dist/`، ولا ينسخ ملفات عمل المستخدمين. أضف ملفات النشر العامة عمدًا إلى قائمة البناء واختبارها. لا تضع سجلّ التجربة أو بيانات شخصية في Git.

## النشر المتكرر

مشروع Vercel مخصص باسم `mirsad-faucet-desk`. إعدادات `vercel.json` في هذا المجلد: **Other**، جذر `ventures/mirsad/first_faucet`، خرج `dist`، الاختبارات ثم البناء، والوظيفة `/api/status`. لا متغيرات سرية أو خدمات مدفوعة مطلوبة.

غيّر المصدر في فرع العمل، شغّل الاختبارات ثم ادفع التعديل إلى الفرع نفسه. عند ربط Git بالمشروع ينتج دفع فرع غير إنتاجي معاينة، وليس بالضرورة تحديث رابط الإنتاج؛ اختبر `/` و`/trial/` و`/trial/offline.html` و`/api/status` ثم انشر الإصدار المختار إلى Production في **المشروع نفسه**. لا تُنشئ مشروعًا جديدًا لكل نسخة ولا تدفع إلى فرع الإنتاج لمجرد الحصول على الرابط. يمكن الرجوع إلى النشر السليم السابق من Deployments.
