# مِرصد الصنبور · Mirsad Faucet Desk

مشروع مِرصد يضم [دليل الصنابير وطرق الدخول](https://mirsad-faucet-desk.vercel.app/faucets/) ومساحة تجربة **Final Autoclaim**. افتح `/trial/` لحساب نافذتك وتدوين وارد مؤكد منك، أو `/trial/offline.html` لتنزيل الدفتر نفسه. يظل السجل في تبويبك؛ ملف الاستئناف الذي تنزّله ليس مشفّرًا. لا تسجّل الأداة في الصنبور، ولا تنفّذ إعلانات أو مطالبات أو تحويلات. نطاق النشر هو هذا المجلد فقط، وليس بقية مستودع Craft Anything أو مشاريع مِرصد الأخرى.

## دليل الصنابير وطرق الدخول (`/faucets/`)

الفهرس لقطة مؤرخة لا قائمة بجميع مواقع الإنترنت: [الفئة Faucet، عملة BTC، الصفحة الأولى](https://faucetpay.io/earn/faucets?category=1&coin=btc) كاملة (50 ملفًا دون الإعلانات)، إضافة إلى CoinDrip وBitEarnix من [الصفحة الثانية](https://faucetpay.io/earn/faucets?category=1&coin=btc&page=2). يعرض خيار العملة الدليل الخارجي الحالي بصفحاته؛ لا يزعم أن العينة المحلية فهرست بقية العملات. هوية الملف في المصدر هي مفتاح إزالة التكرار، لا الاسم أو رابط إحالة. لم نضع أرقام إجمالي مدفوعات الناس كأنها أرباح للزائر.

- `directory/listings.tsv`: رقم صفحة المصدر، معرّف الملف، الاسم والنطاق المعروض كنص. القيود غير المراجَعة لها رابط إلى ملف FaucetPay فقط؛ لا نولّد لها روابط تسجيل أو دخول بالتخمين.
- `directory/review.json`: ثماني ملاحظات من صفحات المشغّلين العامة، مع روابط المصدر والتاريخ. فرّق بين عرض دخول Google، وعرض دخول FaucetPay، والميزة التلقائية الأصلية. الدخول الموحّد بموافقتك لكل موقع ليس إعادة استخدام كلمة سر، وعلامة FaaS لا تثبت الدفع أو أن المشغّل هو FaucetPay. التحذيرات تخص وقت الرصد فقط. عند تحديث اللقطة راجع النصوص والتعداد وأي مشغّل تغيّر دومينه، ولا تحدّث التاريخ دون مراجعة المصادر.
- `directory_page.py` يبني صفحة واحدة تعمل حتى دون JavaScript. البحث والتصفية محليان؛ «قائمتي» تحفظ معرّفات عددية معروفة فقط في `sessionStorage` لهذا التبويب (أو الذاكرة عند المنع). لا جمع لبريد أو كلمة سر أو رمز 2FA، ولا إرسال للبحث، ولا فتح تلقائي أو تسجيل/مكافآت بالنيابة عن الزائر. سياسة CSP تحظر الاتصالات والنماذج والإطارات. لا يزور عامل الأسعار الصنابير.

## التشغيل والتطوير

من `ventures/mirsad/first_faucet`، بمكتبتَي Python وNode القياسيتين دون تثبيت تبعيات أو إعداد مفاتيح:

```sh
node --test trial/model.test.cjs
python3 -m unittest discover -s tests
python3 build_site.py
python3 watch.py --port 8080
```

- `trial/`: نموذج الحساب والحالات، الواجهة العربية والاختبارات. `trial_bundle.build()` ينتج ملف HTML مكتفيًا بذاته، ببصمات CSP وممنوع عليه الاتصال بالشبكة. النسخة المستضافة ونسخة التنزيل من نفس المصدر.
- `hosted/`: الصفحة الرئيسية لنسخة Vercel. `api/status.py`: دالة WSGI للرصد العام، تستعمل المحلل نفسه في `watch.py` **عند الطلب**، مع تخزين مؤقت حتى ساعة، وتراجع عند فشل المصدر. لا Cron ولا خيط دائم أو قاعدة بيانات أو صلاحيات لصنبور على Vercel. اخترنا هذا عمداً بدل نقل حلقة `watch` إلى دالة قصيرة العمر. `watch.py` المحلي وحده يشغّل عاملًا مستمرًا ما دام الأمر يعمل.
- `facts.json`: لقطة يدوية من [الدليل](https://faucetpay.io/faucet/profile/105011) و[الحدود](https://autofaucet.dutchycorp.space/FAQ.php) و[الرسوم](https://faucetpay.io/fees). عند مراجعتها حدّث تاريخها بعد التحقق فقط. حدّ الصلاحية سبعة أيام للحدود ويومان للأسعار. لا يُعرض تقدير عند غياب الأدلة. لا تعني مقارنة العملات أن دفعة قد وصلت.
- `build_site.py` يُعد فقط سبعة ملفات عامة في `dist/`، ولا ينسخ ملفات عمل المستخدمين. أضف ملفات النشر العامة عمدًا إلى قائمة البناء واختبارها. لا تضع سجلّ التجربة أو بيانات شخصية في Git.

## النشر المتكرر

[لوحة مشروع mirsad-faucet-desk في Vercel](https://vercel.com/rmzyaljrnh14-netizens-projects/mirsad-faucet-desk). إعدادات `vercel.json` في هذا المجلد: **Other**، جذر `ventures/mirsad/first_faucet`، خرج `dist`، الاختبارات ثم البناء، والوظيفة `/api/status`. لا متغيرات سرية أو خدمات مدفوعة مطلوبة.

غيّر المصدر في فرع العمل، شغّل الاختبارات ثم ادفع التعديل إلى الفرع نفسه. عند ربط Git بالمشروع ينتج دفع فرع غير إنتاجي معاينة، وليس بالضرورة تحديث رابط الإنتاج؛ اختبر `/` و`/faucets/` و`/trial/` و`/trial/offline.html` و`/api/status` ثم انشر الإصدار المختار إلى Production في **المشروع نفسه**. لا تُنشئ مشروعًا جديدًا لكل نسخة ولا تدفع إلى فرع الإنتاج لمجرد الحصول على الرابط. يعرض `/release.json` بصمتَي الدفتر والدليل ومرجع Git الذي تزوده منصة البناء (أو `null` إن غاب). قارن المرجع بالإصدار المقصود. يمكن الرجوع إلى النشر السليم السابق من Deployments.
